# Continuing UI and reliability pass — 27 October 2026

Started from `1c1f02d` with a clean worktree. Improvements are saved in focused local commits.

## Read a complete variation

Long variation previews ended in a non-interactive `+N` label. The remaining
moves had no buttons, so neither a pointer nor the keyboard could open them
from the move list.

The label now expands that variation and offers **Show fewer** to collapse it.
Sibling variations keep their own expansion, replacement games start with fresh
previews, and collapsing always retains the selected move and its ancestors.
The control keeps keyboard focus, includes its visible text in its accessible
name, and has a 44px touch target on narrow screens and coarse pointers.

Validation:

- `npm run verify`: typecheck, lint, 2,147 tests passed (one existing skip), build.
- Production Chromium, Firefox and WebKit: desktop, phone and 320px/200% text;
  Enter/Space and pointer activation, independent branches, selected deep move
  and note, focus, unchanged PGN export, fitting controls and replacement games.
- Chromium's existing move-list fitting, pointer activation and position-note
  workflows pass. Phone and enlarged-text screenshots were inspected.

## Keep the current move visible in deeply nested studies

An eight-level variation reproduced a missing current-position marker: the
board reached `5. b3` and showed its note, but the move list replaced its branch
with an ellipsis after six levels. The selected path now remains visible at any
nesting level. Unselected deep branches keep a compact preview and offer
**Open deeper line** to navigate into them. Keyboard activation transfers focus
from the replaced opener to its newly exposed move; other controls retain
their focus. Returning to the main line restores the compact preview.

Two component regressions fail before the fix and pass afterward. Production
Chromium, Firefox and WebKit pass the new deep-study and existing expansion
workflows at desktop, phone, 320px/200% text and short landscape sizes. These
cover Enter/Space, focus transfer, direct move/sibling keyboard navigation,
the unique current marker and exact note, and returning to compact previews.
The phone screenshot was inspected. `npm run verify` passes with 2,149 tests
and the existing skip. Dependency audit reports zero vulnerabilities.
